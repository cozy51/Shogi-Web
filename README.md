# 本格和風 将棋 (Shogi-Web)

ブラウザで快適に遊べる、重厚で美しい和モダンデザインの本格将棋Webアプリケーションです。  
React + TypeScript + Vite で開発され、Web Worker による CPU 思考エンジン、Web Audio API による伝統和音響合成、自動局面保存などを完備しています。

---

## 🌟 主な特徴・機能

### 1. ⛩️ シブめの本格和風タイトル画面
- **極上の和モダンビジュアル**: 濃墨色（#14110e）と漆のグラデーション、静かに舞い上がる微細な金箔パーティクル（`<canvas>`）。
- **立体銘字・落款印**: 黄金の立体筆文字タイトル「将棋」と赤落款印「本格」。
- **3D浮彫「王将」駒**: 木目の陰影と光沢を湛えた立体エンブレム。
- **対局再開機能**: 進行中の対局がある場合、手数を添えて前回の局面からワンクリックで再開可能。

### 2. 🔔 伝統和音響（Web Audio API 合成）
外部音声ファイルへの依存ゼロ。ブラウザの Web Audio API を駆使してリアルタイム合成：
- **和鐘・おりんの響き (`playTitleSound`)**: 寺院の鐘や水琴窟を想起させる澄んだ金属倍音と3.2秒の静謐な余韻。
- **竹打・拍子木音 (`playMenuClick`)**: 木と竹の小気味よい接触音。
- **対局開始の和太鼓 (`playGameStartSound`)**: 重低音の胴鳴りと鋭い拍子木の掛け合い。
- **盤上の駒音・王手警戒音・祝賀ファンファーレ・惜敗音**

### 3. 🤖 CPU対戦 & Web Worker AI
- **対戦モード**:
  - 先手対戦 (あなた: 先手 vs CPU: 後手)
  - 後手対戦 (CPU: 先手 vs あなた: 後手)
  - 2人対戦 (1台の画面で対局)
- **難易度**:
  - 入門（初心者向け・ゆらぎ有）
  - 初級（標準的な手筋・駒得重視）
  - 中級（深読み探索・手ごわい）
- **思考時間調整**: じっくり（2.1秒）/ ゆっくり（1.4秒）/ 普通（0.9秒）/ 早指し（0.3秒）

### 4. 👑 わかりやすい決着条件
- **王を取るまで（推奨・明快）**: 王手を放置した場合や見落とした場合も、実際に相手の玉将（王将）を捕獲するまで対局を進行。初心者にも勝敗が直感的にわかります。
- **詰みで終了（伝統ルール）**: 王手がかかって合駒も逃げ場もない詰み局面で即終了。

### 5. ↩️ 親切な「待った」機能（2手復帰）
- 自分の手番で「待った」を押すと、直前の「相手の手」と「自分の手」を合わせた2手を戻し、直前の自分の手番から確実にやり直すことができます。

### 6. 📊 通算戦績記録 & 勝利祝賀演出
- 対局結果（勝敗数、勝率、連勝記録、最高連勝、難易度別成績、直近の棋譜）を `localStorage` に自動記録。
- 勝利時には豪華な金粉・紅白の紙吹雪アニメーションと祝賀ファンファーレが発動。
- 次の一局への誘導（再戦、難易度を上げて挑戦、盤面振り返り、棋譜コピー、タイトルへ戻る）をサポート。

### 7. 🎨 盤面・駒の豊富なカスタマイズ
- **盤の大きさ**: 標準 (540px) / 大 (680px・推奨) / 特大 (820px)
- **マス目の形状**: 正方形 (1:1) / 伝統比率 (1:1.07 縦長)
- **駒の書体**: 二字駒（伝統書体）/ 一字駒（視認性の高い大文字）
- **着手履歴マス強調色**: 青系統（成駒の赤と明確に区別可能）/ 緑系統
- **駒の解説インスペクター**: 盤上や持ち駒をクリックすると、大きな文字と動かし方の解説を表示。

### 8. 💾 自動保存 & 再開
- 駒を1手指すごとに状態が保存されるため、ブラウザをリロードしても対局が途切れません。タイトル画面からいつでも対局室へ復帰できます。

## 🛠️ 技術スタック

- **フロントエンド**: React 19, TypeScript
- **ビルドツール**: Vite 8
- **テストフレームワーク**: Vitest (29件のユニットテスト)
- **音響エンジン**: Web Audio API (オシレーター、倍音フィルター、ノイズ合成)
- **スタイル**: Vanilla CSS (和モダン・レスポンシブ・グラスモフィズム)
- **アイコン・グラフィック**: SVG, HTML5 Canvas 2D

## 🚀 開発環境のセットアップ

### インストール
```bash
npm install
```

### 開発用サーバー起動
```bash
npm run dev
```
ブラウザで `http://localhost:5173/` を開きます。

### テスト実行
```bash
npx vitest run
```

### プロダクションビルド
```bash
npm run build
```
